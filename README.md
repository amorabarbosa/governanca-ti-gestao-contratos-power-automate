# Gestão de Contratos de Governança de TI

Projeto desenvolvido utilizando Microsoft Power Automate para automatizar o controle dos contratos de TI.

## Objetivo

Automatizar o acompanhamento de vencimentos contratuais e notificar os responsáveis antes do prazo final.

## Tecnologias

- Power Automate
- SharePoint Online
- Outlook
- Microsoft 365

## Fluxo

1. Consulta contratos
2. Verifica vencimentos
3. Identifica contratos próximos ao prazo
4. Envia notificações
5. Registra execução
